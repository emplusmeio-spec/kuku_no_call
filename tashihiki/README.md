# たしひきラボ

九九ラボと同じ流れ（スタート → テンキー → 10問セット → メダル → レベルアップ チャレンジ）で、
たし算・ひき算を 30段階で 練習するアプリ。いまは Lv1〜20（第1部 ばらの せかい：20まで）。Lv1 は 0〜5 まとめ、Lv2〜13 で 6〜10 を 5と なんぼで 手あつく（見る・わける・どこまで・5といくつ・5をこえる たしざん・分解・10のなかま・のこり・ちがい）、そのあと くりあがり・くりさがり。さんすうドット トレーニングの コースも ふくむ。
たし算・ひき算の 見せ方は、さんすうドット トレーニングと 同じ 横ながの 10の わく（5×2）。

公開URL：https://emplusmeio-spec.github.io/kuku_no_call/tashihiki/ （先生画面は `?teacher`、子どもは 先生画面で つくる 招待URL）

- 九九ラボと同じ Firebase プロジェクト（kuku-lab）を使い、データは `tashihiki_users` / `tashihiki_invites` / `tashihiki_board` に入る。
- 使う前に Firestore のルールへ `firestore-tashihiki.rules` の 中身を 追加すること。
- `#debug` を つけて ひらくと、ログインなしで どの レベルも ためせる。

## ID とダーツ（九九ラボと同じ しくみ・11/22）

- 子どもの URL は `?i=コード`。1コード＝1人。この URL を開けば、どの端末でも その子の記録が出ます。
- 先生が 発行した コードは、はじめて開いた子が ニックネームを決めた時点で その子のものになります。
- アプリの「しょうたい」を押すたびに 新しいコードが できます（きょうだい・友だち用。先生画面では 枝として つながって見えます）。
- 前の方式で登録した子は、同じ端末で もとの招待URLを開くと 自動で そのコードの持ち主になります。
- ダーツ：ログインボーナス（1日1本）、結果画面でメダルに応じた本数とルーレット（キーは `tashihiki_ステージ番号`）。財布は共通の `darts` コレクション。
- 先生画面の下に ダーツの支払いパネル（九九・よむよむ・たしひき 共通）。
- おとな画面に いまの子の URL と 版（例 11/22a）を表示。

## 開発方針（11/22 改定）

教える（数の意味・桁）／なれる（補数・分解の自動化）／ためす（タイルを自分で動かして 5・10 のかたまりを作る）を分ける。計算の しかたは 教えない。ヒントは出す。

- 問題は その段で出る問題を 全部1まいずつ入れた山を まぜて 出す（全段）。
- 一度クリアした段へは レベルアップチャレンジなし。
- Lv3 目かくしなし・時間で判定。Lv6・8 タイルを おすと となりへ（時間内に動かさなければ「こう うごかすと はやいよ」）。Lv6・8 で どうなら Lv3〜5 の たしかめテスト（6問）→ できなかった段へ。
- Lv9 3セット クリアできなければ Lv6 へ。Lv10・11 見えているタイルを おすと 左右が入れかわる。
- Lv12 かたまりを 数直線へ ドラッグ。Lv13 おすと消える（5のかたまりは まとめて）。Lv14 下の段を おすと 左よせ・右よせ。
- Lv15 ひきざん（式だけ）を新設（どうなら Lv13 へ）。以前の Lv15 以降は 1つずつ うしろへ（記録は自動で引っこし）。
