# よむよむ　ことば一覧（習得をめざす語彙・機能語）

- **ことばチェック**：そのレベルで新しく確かめることば（ことばカードつき）。
- **読む問題**：そのレベルの7分野の問題で、答えを決める手がかりになることば。
- 同じことばは2度出さない。似たことばが出るときは、**前の段の発展**として出す（右端の列）。
- ことばチェックは、前に手をつけてまだクリアしていないことばを、次のレベルにも持ちこす（テストプレイ `?test` では持ちこさない）。

| 2 | もらう（「に」は渡す側）、そこ | ぜんぶ、〜から（わけ） | みぎ・ひだり、ながい・みじかい、〜こ・〜ばんめ／こんちゅう・さかな／まるがた | ぜんぶ → Lv20 部分否定 |

| 6 | とられた、文の内容を指す「それ」 | や（〜など）、〜たら | ななめ、さかさま、むき、おもい・かるい、右から〇ばんめ、おととい・あさって／あいさつ・さんぽ／2とびならび | 「それ」＝〜こと → Lv19 文全体を指す「これ」、〜たら → Lv22 ならば |

## 段3：小5〜中3（Lv19〜30）　文を正確に読む（構造と推論）
| Lv | ことばチェック | 読む問題で扱う機能語・型 | 定義（辞書・理数） |
|---|---|---|---|
| 19 | 〜につれて、文全体を指す「これ」、〜させられる | 名詞を説明する部分の重なり（AがBに頼まれて作ったC）、読点で変わるかかり方、前者・後者、使役の言いかえ、二重否定（〜ない人はいない）、部分否定 | リサイクル／偶数 |
| 20 | 二重否定、前者・後者、全部が〜とはかぎらない | 「〜の〜の〜の」の連なり、「この変化・この工夫…」の言いかえ | ボランティア／約数 |
| 21 | 割合の言いかえ、この〜、読点の位置 | 半分＝50%＝2人に1人、割合が増えても数が増えたとは言えない | 輸入／平均 |
| 22 | 省略された主語、逆、対偶 | 「〜てくれる・借りる・教わる」から主語を決める、AならばB の逆・裏・対偶 | 義務／線対称 |
| 23 | 修飾の範囲、「〜だけが」と「〜なら」、比例する | 同じ文で「〜なる／〜する」を問いわける、必要と十分、比例の言いかえ | 擬人法／比例 |
| 24 | のこりから決める | 「その〇%」の「その」（全体）、条件を組み合わせて順位を決める | 多数決／公倍数 |
| 25 | 名詞の連なり、ただし、〜のみ | 「AによるBの減少」（される側／させる側）、座標 | 生産者／絶対値 |
| 26 | 〜を〜という | RSTの形（易・普）：係り受け・照応・同義文・推論 | 公共施設／素数 |
| 27 | 〜のうち | RSTの形（普・難）：割合の内訳、重なり（両方） | 対義語／文字列の条件 |
| 28 | 〜以外の場合 | 主張の根拠になるグラフ | 外来語／初めての定義（豊かな数） |
| 29 | 〜を除くと | RSTの形（難・超難）：長い文の主語、使役、因果の向き | 契約／得点のルール |
| 30 | 〜に応じて | いくつもの条件を同時に満たす図（原点と点を通り軸に接する円） | 再生可能エネルギー／接する |

## 段をまたいで発展することば（同じ語ではなく、使い方が上がる）
| 段1（Lv1〜7） | 段3（Lv19〜30） | 上がるところ |
|---|---|---|
| だけ、しか〜ない | 〜だけが・〜のみ・「〜だけが」と「〜なら」 | 「だけ」を条件として読む（必要と十分） |
| ぜんぶ、みんな、ひとつも〜ない | 二重否定、全部が〜とはかぎらない | 打ち消しの重なり・範囲 |
| あげる・もらう、かす・かりる、くれる | 省略された主語、〜させられる | 書かれていない主語を動詞の向きで決める |
| それ（もの）、それ（〜こと） | 文全体を指す「これ」、この〜（言いかえ）、その〇% | 指す範囲が文全体・全体と部分になる |
| 〜たら、だから、〜から | AならばB の逆・対偶、〜につれて | 条件と因果を区別する |
| いがい、どちらか | 〜以外の場合、〜を除くと | 例外を除いた残りを考える |
| いちばん、〜ばんめ | のこりから決める（順位） | 条件を組み合わせて決める |
