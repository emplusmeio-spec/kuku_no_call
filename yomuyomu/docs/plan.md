# よむよむ チャレンジ　30レベル計画

## 1. このアプリの役割
**よむよむ ＝ 文を正確に読む（構造と推論）に特化したアプリ。**

| | よむよむで扱う | 扱わない（別の教材へ） |
|---|---|---|
| 構造 | だれが・何を・どれを説明しているか（係り受け）、指す先（照応）、言いかえ（同義文） | — |
| 推論 | 書いてあることから言えること・言えないこと（正しい／まちがい／判断できない） | — |
| 図と定義 | 文を図・グラフにする、定義を読んで当てはめる | — |
| 英語 | — | 英語の機能語（too・only・even…）、英文の構造 → 英語読解力向上工場（読解ドリル・二層ドリル・説明さがし） |
| 国語 | — | 物語の気持ち（きもちのことば）、表現技法、漢字、作文 |
| 教科の知識 | — | 計算・理科社会の知識そのもの → 九九ラボ、算数アプリなど |

算数・理科・社会のことば（偶数・比例・輸入など）は、**教えるためではなく、定義を読んで当てはめる練習の材料**として使う。
初めて見ることばでも、本文の定義を読めば解ける問題にする。

## 2. 7つの分野（RST と同じ）
| 分野 | 何を見るか |
|---|---|
| 係り受け解析 | 主語・述語、修飾がどこにかかるか、受け身・使役で だれが何をしたか |
| 照応解決 | 指示語（これ・それ・その〇%・前者）が何を指すか |
| 同義文判定 | 2つの文が同じ意味か（言いかえ） |
| 推論 | 本文から「正しい／まちがい／判断できない」 |
| イメージ同定 | 文を図・グラフ・座標に置きかえる |
| 具体例同定（辞書） | ことばの定義に当てはまる例を選ぶ |
| 具体例同定（理数） | 数・図形の定義に当てはまる例を選ぶ |

## 3. 進め方（どのレベルも同じ）
- **① ことばチェック**：そのレベルで新しく使う「構造と推論のことば」を確かめる（指示は読み上げ、まちがえたらことばカード）。
- **② よむ れんしゅう**：7分野。問題は「型 × ことば」から毎回つくる。
- **マスター**：ことば・型ごとに、2回つづけて正解（一度でもまちがえたら3回）でクリア。
- **昇段**：そのレベルのことばと型を全部クリアで合格。
  - 下のレベルを とばして始めた子は、手をつけていない下のことばでは止まらない（手をつけて、まだのことばは必要）。
- **記録**：がんばりグラフ（日付×レベル）、つまずき（まちがい回数）、先生画面。

## 4. 表記と文章
| レベル | 表記 | 文章 |
|---|---|---|
| 1〜3 | ひらがなのみ（カタカナもひらがな）・分かち書き | 1〜2文 |
| 4 | カタカナ可 | 2文 |
| 5〜18 | 習った漢字＋ふりがな・分かち書き | 2〜4文 → 1段落 |

## 6. 用語の入れ方のルール
1. 初めて出すことばは、そのレベルのことばチェック（または辞書・理数の定義問題）で確かめてから、同じレベル以降の読む問題で使う。
2. 推論のことばは、初めて出すとき「そのことばで答えが決まる問題」にする（例：「や」→ ほかにもあるかもしれない→判断できない）。
3. 定義の問題は、知識ではなく本文の定義だけで判断できるようにする（ひっかけは「条件の片方だけ満たすもの」）。
