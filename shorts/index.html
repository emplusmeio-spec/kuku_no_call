ごほうび動画の設定（おとな）

見られる時間

1日の上限（分） 0 = 上限なし。ごほうびが多くても、1日にこれ以上は見られません。
本番では、九九ラボのメダルやダーツから自動で時間が入る形にします（ShortsWallet.grant(分, 理由)）。

許可したチャンネル

ここに入れたチャンネルのショートだけを、1日1回、自動で集めます。@ハンドル（例：@nhk_eteleなど）か、UC から始まるチャンネルIDを入れてください。

    動画を1本ずつ入れる

    ショートのURL（youtube.com/shorts/… や youtu.be/…）を1行に1つ。APIキーがなくても使えます。

    集めた動画

    子どもが ♥ を押したチャンネルほど、多めに出ます。

      YouTube Data API キー

      チャンネルから自動で集めるときだけ必要です。Google Cloud で「YouTube Data API v3」のキーを作り、使えるサイトをこのアプリのURLだけに制限してください。1回の取得で使う量は、チャンネル1つにつき1〜2ユニット（1日の無料枠は10,000）。

      外へ出さないしくみ

      ・動画の上に透明な板をかぶせているので、YouTube のロゴ・タイトル・おすすめを押せません。
      ・動画が終わると、おすすめが出る前に次の動画へ進みます。
      ・チャンネル名は文字だけで、リンクにしていません。
      ・時間は「再生しているあいだ」だけ減り、端末に保存するので、開き直しても増えません。
