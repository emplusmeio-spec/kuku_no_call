# オンライン版の準備（九九ラボと同じ管理）

よむよむ チャレンジは、九九ラボと同じ Firebase プロジェクト（`kuku-lab`）を使います。
データは九九ラボとは別の置き場所に入るので、九九ラボの先生画面や生徒一覧とは混ざりません。

| 置き場所（コレクション） | 中身 |
|---|---|
| `rst_users` | 子ども1人ずつの記録（ニックネーム・進み具合・しょうたい元）。ドキュメントIDが「ひきつぎ URL」の鍵 |
| `rst_invites` | しょうたいコード（先生が発行したもの・子どもが友だちに渡すもの） |
| `rst_board` | みんなの様子 用（ニックネーム・レベル・★の数だけ） |

## 1. Firestore のルール
九九ラボの ルールに よむよむの分を 足した **完成形** が `rst-kids/docs/firestore.rules` です。

1. Firebase コンソール（terauchi@em-plus.net の Google アカウントで ログイン）→ プロジェクト **kuku-lab** → Firestore Database → **ルール** タブ
2. **まず いま 公開されている ルールを 確認**：`firestore.rules` の「九九ラボ」の部分（users / board / invites）と 同じか 見くらべる
   - 同じ → 3 へ
   - ちがう（古い・新しい）→ 貼らずに、いまの ルール全文を Claude に 送る（それに よむよむ の分を 足した版を つくりなおす）
3. ルール欄を 全部 消して `firestore.rules` を 貼り、**公開** を 押す
4. 九九ラボ（https://emplusmeio-spec.github.io/kuku_no_call/ ）が これまでどおり 動くか 確かめる

よむよむ の分は 九九ラボと 同じ きびしさ です（一覧は先生だけ、子どもの記録は鍵を知っている端末だけ、みんなの様子は 決まった項目だけ）。

## 2. 置き場所（GitHub Pages）
claude.ai の公開ページでは Firebase が読みこめないため、**端末の中だけで動く版** になります（記録はその端末だけ、印刷もできません）。

**いまの置き場所：九九ラボと 同じ リポジトリ（2026/11/02 に配置ずみ）**
`emplusmeio-spec/kuku_no_call`（公開・GitHub Pages 済み）の `yomuyomu/` フォルダに、`rst-kids/` の公開用ファイル（index.html・style.css・*.js）を コピーして 置いている。
**このリポジトリで rst-kids を 直したら、kuku_no_call/yomuyomu にも 同じ ファイルを コピーして main に プッシュ する。**
- 公開URL：`https://emplusmeio-spec.github.io/kuku_no_call/yomuyomu/`（先生画面は `?teacher`）
- リポジトリを 公開に したり、Pages を 新しく 設定したり しなくてよい
- 承認済みドメイン（`emplusmeio-spec.github.io`）も 九九ラボで 設定ずみ なので そのまま
- 記録の 置き場所（ブラウザ）は 九九ラボと 名前を 分けてあるので まざらない

**べつの方法：このリポジトリ（el_convert_html）で 公開する**
1. ブランチを `main` に マージ　2. Settings → General → Change visibility → Public（いまは 非公開）
3. Settings → Pages → Deploy from a branch → main / (root)　4. `https://emplusmeio-spec.github.io/el_convert_html/rst-kids/`

## 3. つかいかた（URL が その子の かぎ：1コード 1人）
1. 先生が `…/yomuyomu/?teacher` を開いてログイン → 「しょうたい URL を 発行」（1人に 1つ。メモに 子どもの なまえ）
2. 出てきた URL（`…/yomuyomu/?i=コード`）を その子の 保護者に LINE などで 送る
3. 子どもが はじめて その URL を 開くと ニックネームを きめる → その URL は その子の もの に なる
4. つぎからは、**どの 端末で 開いても、その URL で その子の 記録から つづく**（ニックネームは きかれない。端末には 記録しない）
5. きょうだいは 1人ずつ べつの URL を 発行する
6. 子どもは「ともだちを しょうたい」で、おすたびに あたらしい URL を 1つ つくって 渡せる（先生画面では つながりとして 見える）
7. 以前の つくりで おなじ URL に 2人 登録されていた場合は、先生画面を 開いたときに 整理され、その URL を 開くと「どちらが やる？」が 出る

## 4. テストプレイ（`?test`）
`…/yomuyomu/?test` を ひらくと、全レベル（Lv19〜30 も）すぐ 入れます。記録は その端末だけ（`rst-kids-test`）で、サーバーの 記録・ダーツには さわりません。上の「記録を けす」で やりなおせます。先生画面の 下にも リンクがあります。

## 5. ダーツ（ごほうび。九九ラボ・よむよむ 共通）
- ルールに `match /darts/{wid}` を 追加してください（`firestore.rules` の いちばん下）。追加するまでは ダーツは 出ません（アプリは ふつうに 動きます）。
- もらい方（九九と よむよむで べつべつに 数える）：ログインで 1日1本／その日 初めての 銅メダルで 1本／その日 初めての 銀メダルで さらに 1本＋銀ルーレット（1本×8・2本×3・5本×1）／その日 初めての 金メダルで 金ルーレット（銀の 2倍）。その日 初めての メダルが 金なら 銅・銀の 2本＋金ルーレット。
- 演習の おわりに メダルと いっしょに「いま もっている本数」が 出ます。回していない ルーレットは よむよむの ホーム・つぎの 演習の おわりに 出ます。
- 先生画面の「ダーツ」：支払いの 欄は はじめ 全部の本数。数を かえて「支払う」。同じ子の 九九・よむよむの 財布は 2つに チェックして「1つにまとめる」（まとめた あとは どちらの アプリでも 同じ 財布）。
